# a2rp LAB

An experimental technology playground for creative coding, modern interfaces, AI concepts, frontend experiments, and emerging web technologies.

![a2rp LAB Preview](preview.png)

## Overview

a2rp LAB is a digital experimentation space focused on building, testing, and exploring ideas across modern web development and creative technology.

The project is designed as a showcase for experimental interfaces, interactive concepts, visual systems, frontend engineering, and technology-driven ideas.

## Features

- Modern experimental UI
- Responsive layout
- Creative frontend interactions
- Technology-focused visual design
- Modular React architecture
- Styled-components based styling
- Reusable components
- Optimized production build
- GitHub Pages deployment

## Tech Stack

## Getting Started

Clone the repository:

```bash
git clone https://github.com/a2rp/a2rp-test.git
```

Move into the project directory:

```bash
cd a2rp-test
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Deployment

The project is configured for deployment on GitHub Pages.

The Vite base path is:

```js
base: "/a2rp-test/";
```

Deploy the latest production build:

```bash
npm run deploy
```
